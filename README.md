# Анализ данных с визуализацией и машинным обучением

## О проекте
Это веб-приложение на Flask, которое позволяет загружать CSV или XLSX файлы, выбирать целевой столбец и признаки для анализа, строить статистические отчёты, графики и обучать модель случайного леса для предсказания. Все результаты отображаются в удобном виде на странице.

## Что сделано
- Загрузка файлов CSV и XLSX с фронтенда.

- Парсинг и отображение столбцов для выбора пользователем.

- Анализ данных: описательная статистика, пропущенные значения.

- Визуализация данных: гистограмма целевой переменной, корреляционная матрица.

- Обучение модели RandomForestRegressor на выбранных признаках.

- Отображение результатов модели: MSE, RMSE, важность признаков.

- Отправка и получение данных через JSON API.

- Обработка ошибок и отображение сообщений пользователю.

- Настройка Matplotlib для работы без GUI (backend Agg).

## Использование
- Загрузите CSV или XLSX файл с данными.

- Выберите целевой столбец (target) и признаки (features).

- Нажмите "Анализировать".

- Просмотрите статистику, графики и результаты модели.
